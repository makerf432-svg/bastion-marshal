# Bastion Marshal

**Live Demo:** https://suptnt-324.itch.io/bastion-marshal

## Overview
A node-based Real-Time Strategy (RTS) game built with custom troop production logic, territory capture mechanics, and AI opponent simulation. Currently live on Itch.io and in early release on CrazyGames.

## Key Features
- Real-time node territory capture and troop routing mechanics.
- Dynamic AI opponent decision-making and level winnability simulation.
- Two distinct AI difficulty tiers: **Human** (standard tactical AI) and **Grandmaster** (advanced aggressive AI).
- Custom UI, level progression, and balance systems.

## Active Development Roadmap (In Progress)
- Expanding multi-node AI difficulty scaling and new map mechanics.
- Optimizing troop pathfinding and performance across complex levels.
- Adding new player progression features and expanded campaign maps.
- Designing and implementing new node structures alongside the Armory and Fortress systems.
- Improvement in UI to highlight quick play button.
